# SpatialView 网页版

网页版用于在没有平板时，在 Ubuntu 电脑上测试服务端。页面与平板 APK 中的完全相同；启动脚本在本机提供页面，并用 Chrome 或 Chromium 的应用窗口打开。接口和服务端的要求见《服务端对接接口文档》。

压缩包中的文件：

- `dist/`：页面
- `start.sh`：启动脚本
- `README.md`：本说明

第一次启动后，解压目录中会多出 `profile/`，用于保存浏览器数据和工程入口中修改的配置。

## 运行环境

- Ubuntu 22.04。
- python3：Ubuntu 自带，启动脚本用它在本机提供页面。
- Google Chrome 或 Chromium。Ubuntu 22.04 默认的 Firefox 没有测试过，启动脚本也不会使用它。任选一种方式安装：
  - 从 https://www.google.com/chrome/ 下载 .deb 安装包，执行 `sudo apt install ./google-chrome-stable_current_amd64.deb`；
  - 执行 `sudo snap install chromium`。
- 电脑能访问服务端主机的 9090 端口（rosbridge）和 8080 端口（文件服务）。

## 启动

1. 把压缩包解压到家目录下的非隐藏目录中，例如：

   ```bash
   tar -xzf spatialview-web-0.1.3.tar.gz -C ~
   ```

   Snap 版 Chromium 只能访问家目录下的非隐藏目录，不要解压到 `/tmp`、`/opt` 或以 `.` 开头的目录中。

2. 在终端中运行启动脚本：

   ```bash
   cd ~/spatialview-web-0.1.3
   ./start.sh
   ```

   结果：打开 SpatialView 窗口，终端显示页面地址 `http://127.0.0.1:8090/`。

3. 确认顶部状态栏中"服务"一项显示"已连接"。一直没有显示"已连接"时，见"故障排查"。
4. 测试结束后关闭窗口。启动脚本随后停止页面服务并退出。在终端中按 Ctrl+C 也可以退出。

启动脚本的选项：

- `SPATIALVIEW_PORT`：页面端口，默认 8090，例如 `SPATIALVIEW_PORT=8091 ./start.sh`。换端口后，工程入口中保存的配置不再生效，需要重新设置。
- `SPATIALVIEW_BROWSER`：浏览器命令。默认依次查找 `google-chrome`、`google-chrome-stable`、`chromium`、`chromium-browser`。
- 其余参数原样传给浏览器，例如 `./start.sh --start-maximized`。

## 换用新版本

压缩包和解压目录的名称中有版本号，新版本解压后是一个新目录，不会覆盖旧版本。

1. 关闭正在运行的 SpatialView 窗口。
2. 按"启动"解压并运行新版本。
3. 新目录中没有旧目录的 `profile/`。在工程入口中改过服务端地址的，需要重新设置（见"服务端地址"）。
4. 新版本运行正常后，可以删除旧版本的目录。

## 服务端地址

默认连接 `ws://192.168.1.10:9090`（rosbridge）和 `http://192.168.1.10:8080`（文件服务），即接口文档 14.1 中服务端主机的地址。

地址不同时，在工程入口中修改。打包时启用了工程入口才能使用，密码另行告知。

1. 在顶部状态栏最左侧的"SpatialView"字样上按住鼠标左键 5 秒，按住期间鼠标不要移出这几个字。

   结果：弹出"工程入口"密码框。

2. 输入密码，单击"确定"。

   结果：打开"工程设置"面板。

3. 修改"ROSbridge 地址"和"HTTP 地址"，单击"保存"。

   结果：页面重新加载，按新地址连接。

修改后的配置保存在 `profile/` 中，下次启动仍然有效。在"工程设置"面板中单击"恢复默认"，或者删除 `profile/` 目录，可以恢复默认地址。

## 鼠标和键盘操作

| 平板上的操作                     | 电脑上的操作  |
| -------------------------------- | ------------- |
| 单指拖动：旋转视角               | 按住左键拖动  |
| 双指捏合：缩放                   | 滚动鼠标滚轮  |
| 点击按钮、点选表面               | 单击左键      |
| 长按"SpatialView" 5 秒：工程入口 | 按住左键 5 秒 |
| 返回键                           | Esc 键        |

按 F11 可以切换全屏。

## 与平板的差别

- 电脑的 GPU 与平板不同，帧率和加载耗时不能代表平板。性能指标以平板上的测量为准。
- 界面按 1280 × 800 设计。窗口更大时只加宽三维区；窗口更小时，界面可能显示不全。
- 屏幕常亮、隐藏系统栏等平板上的功能，在电脑上不起作用。

## 故障排查

**启动时提示找不到 Google Chrome 或 Chromium**

按"运行环境"安装其中一种。浏览器命令不在默认列表中时，用 `SPATIALVIEW_BROWSER` 指定。

**启动时提示端口已被占用**

通常是已经打开了一个 SpatialView，关闭它后重新启动。端口被其他程序占用时，用 `SPATIALVIEW_PORT` 换一个端口。

**"服务"一直没有显示"已连接"**

连接不上服务端时，"服务"显示"正在连接…"或"连接断开，正在重连…"。

1. 在这台电脑上执行 `curl -I http://192.168.1.10:8080/`。有 HTTP 响应（包括 403、404）说明网络能连通服务端主机。
2. 在服务端主机上确认 rosbridge 正在运行，并监听 9090 端口。
3. 服务端地址不是 192.168.1.10 时，按"服务端地址"修改。

**出现"模型加载失败"或"规划加载失败"告警**

执行 `curl -I http://192.168.1.10:8080/models/<model_id>.glb`，确认文件存在，并且响应中有 `Access-Control-Allow-Origin` 头。页面来自 127.0.0.1，读取服务端的文件属于跨域访问，nginx 必须按接口文档 14.3 返回这个头；平板上也是这样。规划文件在 `/plans/` 下，检查方法相同。

**三维区空白**

在普通的 Chrome 窗口中打开 `chrome://gpu`，查看 WebGL2 是否可用。没有可用 GPU 的电脑（例如虚拟机）使用软件渲染，可以显示，但会明显变慢。

**其他问题**

在 SpatialView 窗口中按 Ctrl+Shift+I 打开开发者工具，查看 Console 中的错误，以及 Network 中的文件请求和 WebSocket 报文。
